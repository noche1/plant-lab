# 식물 초능력 발명소

식물 두 가지의 초능력을 합쳐 발명품을 만들고, 반 전체 전시장에 올리는 3학년 수업 웹앱입니다.

## 학생 이름을 다루는 방식

- 구글 시트(서버)에는 **번호, 고른 식물, 발명품 내용**만 저장합니다. 이름은 저장하지 않습니다.
- 번호마다 선생님이 정한 그림(🦒 등)이 붙어서, 학생 기기에서는 "🦒 7번"으로 보입니다.
- 선생님이 [선생님] 메뉴에서 명렬표를 넣으면 **그 기기 브라우저에만** 저장되고, 그 기기에서만 실명으로 보입니다.
- 기록 지우기는 시트 스크립트에 정해 둔 관리 비밀번호가 있어야 합니다. 비밀번호는 이 저장소 코드에 없습니다.

## 파일

- `index.html` 앱 전체 (Vercel 정적 배포)
- `apps-script/Code.gs` 구글 시트 확장 프로그램 > Apps Script 에 붙여넣는 저장소 스크립트 (비밀번호 자리는 비어 있음)
